MY AMANAH – FAMILY FUNDS STARTER

1. Open config.js.
2. Replace SUPABASE_URL with your Supabase Project URL.
3. Replace SUPABASE_PUBLISHABLE_KEY with your publishable key.
4. Never use a secret key or service_role key in browser code.
5. Open this folder in Visual Studio Code.
6. Run index.html using the Live Server extension.
7. Sign in with your Supabase Authentication user.

Required views:
- public.account_balances
- public.loan_balances
- public.personal_money_position
